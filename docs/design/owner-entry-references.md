# Kierunek wejścia — projekty właściciela

2026-10-05. Oryginały skopiowane bez zmian: `owner-entry-mobile-v1.png` i `owner-entry-desktop-v1.png`.

Właściciel nadal obrabia projekty. Referencje pokazują turkusowe drzwi z mazem 3S, miedziano-pomarańczowe światło, ciemne tło i czytelny formularz. Nie są gotowym assetem aplikacji ani instrukcją odwzorowania całej sceny.

Docelowo: działający formularz jako HTML, grafika bez namalowanych pól, rozjazd dwóch połówek wejścia odsłaniający gotowe lobby. Rejestracja i logowanie wymagają osobnego etapu integracji z prawdziwym uwierzytelnianiem. Bieżący pakiet dotyczy tylko charakteru lobby.
